# Gamer Profile and Friends

Design only: a real original-XNA Xbox Live provider must supply profile, picture and friend collections. FNA has no operational provider.

## Run and controls

This topic has no FNA runtime entry.

## Defining checks

Requires provider-backed sign-in, asynchronous requests, sign-out cancellation and error checks on a supported original-XNA platform.

## Status and boundaries

**Platform blocked:** FNA does not implement the Xbox Live provider. No fake friends or profiles are supplied. See [requirements.md](requirements.md) for the original-platform design.
