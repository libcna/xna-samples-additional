# XACT Streaming

AudioEngine and SoundBank play two looping cues from a real streaming WaveBank. A public cue variable drives a volume RPC, while a Music category controls the mix.

## Run and controls

```sh
python3 tools/run.py --sample xact-streaming
python3 tools/run.py --headless --sample xact-streaming --frames 150 --verify --capture .artifacts/xact-streaming.png
```

Run these commands from the repository root. Space transitions the added layer over one second; P pauses/resumes; Up/Down change category volume. Left/Right switch samples; R reloads the active sample; Esc exits the browser.

## Defining checks

Native cue state, variable roundtrip and pause/resume are checked. The bank format's streaming flag is also verified.

## Status and boundaries

The original banks are generated by a narrow, documented fixture builder. The matching XAP authoring project still requires independent XactBld3 validation. Dummy audio checks state/submission, not audible quality.
